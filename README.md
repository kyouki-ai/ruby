# Ruby

**Слушай лекцию. Конспект соберётся сам.**

Десктоп-приложение для Windows + расширение для браузера. Слушает лекцию —
с микрофона в аудитории или прямо во вкладке браузера (Google Meet, Zoom Web,
YouTube, сайт со слайдами) — и собирает структурированный markdown-конспект,
с делением по предметам и лекциям, как в обычном приложении для заметок.

🔗 **Сайт и скачивание:** [kyouki-ai.github.io/ruby](https://kyouki-ai.github.io/ruby/)

## Возможности

- **Чат с ИИ по всем конспектам** — открывается сразу при запуске. Можно
  спросить «какое дз по матеше» без выбора предмета — Gemini сам находит
  нужные конспекты среди всех сохранённых лекций.
- **Живой транскрипт и конспект** — во время записи видно, что реально
  расшифровывается, а не просто индикатор «идёт запись».
- **Запись без браузера** — кнопка «Начать запись с микрофона» прямо в
  приложении, для лекций в аудитории.
- **Удалённый запуск записи в браузере** — можно начать/остановить запись
  вкладки прямо из приложения, не открывая попап расширения.
- **Уведомление, если зовёт преподаватель** — опционально: если в
  расшифровке речи прозвучит указанное имя, приходит системное уведомление
  на компьютер (полезно, если прослушал, что тебя вызвали).
- **Пересборка конспекта** — если сборка через Gemini не удалась при записи
  (лимит/перегрузка), можно пересобрать её позже из сохранённой расшифровки,
  прямо из карточки лекции.

## Как это работает

1. Аудио лекции стримится (по WebSocket на `localhost:8787`, только локально)
   в десктоп-приложение (`desktop/`, Electron + TypeScript) — с микрофона
   или из вкладки браузера через расширение (`extension/`, Manifest V3).
2. Расширение при захвате вкладки также раз в ~25 секунд отправляет
   скриншот + текст страницы, если включён режим со слайдами.
3. Десктоп-приложение отправляет аудио-куски и слайды в **Google Gemini
   API** (бесплатный тариф, свой ключ у каждого пользователя) — Gemini
   расшифровывает речь, описывает слайды без текстового слоя и после
   остановки записи собирает всё в markdown-конспект.
4. Конспект сохраняется на диске в обычной папке:
   `<Предмет>/<Дата - Название лекции>/notes.md` — видно и без приложения.

## Настройка (один раз)

1. Запустить приложение (`cd desktop && npm install && npm start`).
2. Открыть **«Настройки»** (шестерёнка в шапке).
3. Получить бесплатный ключ на https://aistudio.google.com/apikey (нужен
   только Google-аккаунт, банковская карта не требуется) и вставить его в
   поле «Gemini API» → «Сохранить». Ключ хранится на диске в зашифрованном
   виде (через Windows DPAPI) и никуда, кроме Google, не отправляется.
4. При желании — сменить папку для хранения конспектов (по умолчанию
   `Документы/AI Lecture Notes`) и вписать своё имя в «Уведомление, если
   зовёт преподаватель».

Каждый, кто ставит это приложение, вставляет **свой** бесплатный ключ — для
всех бесплатно, ничего не платится ни автором, ни пользователем.

## Приватность и безопасность

- Аудио лекции, скриншоты слайдов и текст конспекта отправляются в Gemini
  API для обработки — это неизбежно при использовании облачного ИИ.
  Приложение не «полностью офлайн» и не «анонимное»: обработка идёт на
  серверах Google под твоим API-ключом, на условиях самого Google.
- Никакой телеметрии, аналитики или сторонних серверов в приложении нет —
  единственный внешний трафик — вызовы Gemini API.
- Локальный WebSocket-сервер слушает только `127.0.0.1` — недоступен по
  сети другим устройствам.
- API-ключ хранится зашифрованным на диске, не в открытом виде.
- Все конспекты — обычные файлы на твоём компьютере, в папке, которую ты сам
  выбираешь. Ничего не улетает в облачное хранилище автоматически.

## Загрузка расширения в браузер

1. Chrome/Edge → `chrome://extensions` (или `edge://extensions`).
2. Включить «Режим разработчика».
3. «Загрузить распакованное расширение» → выбрать папку `extension/`.
4. В приложении на экране записи появится карточка «Расширение подключено» —
   запись в браузере можно запускать прямо оттуда.

### Режимы записи

- **Звук + слайды** — онлайн-лекция в браузере: звук вкладки, скриншоты и
  текст слайдов.
- **Только звук** — то же самое, но без захвата слайдов.
- **Микрофон** — офлайн-лекция в аудитории, браузер не нужен.

## Структура репозитория

```
desktop/     Electron-приложение (окно, WebSocket-сервер, вызовы Gemini, UI)
extension/   Браузерное расширение Manifest V3 (захват аудио и слайдов)
docs/        Сайт проекта (GitHub Pages) — kyouki-ai.github.io/ruby
```

## Известные ограничения

- `chrome.tabs.captureVisibleTab` снимает скриншот активной вкладки окна —
  если во время записи со слайдами переключиться на другую вкладку в том же
  окне, слайды будут сниматься с неё. Открой лекцию в отдельном окне браузера,
  если хочешь параллельно заниматься другими делами.
- Бесплатный тариф Gemini API имеет дневной лимит запросов — при частых
  ошибках в error.log попробуй увеличить интервалы захвата слайдов в
  настройках.
- Расшифровка идёт кусками по ~30 секунд, а не пословно в реальном времени.
