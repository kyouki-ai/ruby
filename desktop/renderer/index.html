Подключи бесплатный ИИ

Приложение расшифровывает речь и собирает конспект через Gemini API — бесплатно, свой ключ на каждого пользователя.

  1. Открой aistudio.google.com/apikey и войди с Google-аккаунтом.
  2. Нажми «Create API key» — карта не нужна.
  3. Скопируй ключ и вставь его сюда.

Gemini API

ИИ работает через бесплатный облачный Gemini API — обработка идёт на серверах Google, а не на этом ПК. Получи свой бесплатный ключ (без карты) на aistudio.google.com/apikey и вставь ниже. Ключ хранится у тебя на диске в зашифрованном виде и никуда, кроме Google, не отправляется. Если во время долгого дня лекций упрёшься в дневной лимит бесплатного тарифа — можно вставить сюда ещё один бесплатный ключ через запятую, и приложение будет чередовать их.

Groq API — для распознавания речи (необязательно)

Расшифровка звука — самый частый вызов ИИ за лекцию, и он может забирать себе весь дневной лимит Gemini. Если вставить сюда ещё и бесплатный ключ Groq (console.groq.com/keys), распознавание речи пойдёт через него, а Gemini останется свободен для конспекта, чата и теста. Слайды по-прежнему обрабатывает Gemini — Groq для этого не подходит. Без ключа всё работает как раньше, просто на Gemini.

Хранилище заметок

Все конспекты хранятся локально на этом компьютере, в обычных папках — их видно и без приложения.

Захват
Уведомление, если зовёт преподаватель

Если во время записи в речи прозвучит это имя — придёт уведомление на компьютер, даже если окно свёрнуто. Полезно, если не расслышал, что тебя вызвали. Оставь пустым, чтобы отключить.

Голосовые маркеры важных моментов

Скажи эту фразу вслух во время записи — момент попадёт в живой транскрипт с пометкой и будет отдельно выделен в итоговом конспекте. Оставь пустым, чтобы отключить.

Подробность конспекта

«Кратко» — сжатые буллеты по ключевым мыслям (по умолчанию). «Подробно» — развёрнутый конспект почти на весь материал лекции, вплоть до ~10 страниц, с полными объяснениями, а не короткими пунктами. Занимает больше времени на сборку.

Как подключить расширение в браузере

Один раз — нужно для онлайн-лекций со слайдами на экране. Для офлайн-лекций это не нужно вовсе.

1

Открой в Chrome страницу настроек расширений.

2

Вставь адрес в браузер и включи переключатель «Режим разработчика» справа вверху.

3

Нажми «Загрузить распакованное расширение» и выбери папку, которая откроется по кнопке ниже.

Каждый раз: открой лекцию в браузере → нажми на иконку расширения → выбери, что записывать.
