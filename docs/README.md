# Ruby

**Слушай лекцию. Конспект соберётся сам.**

Ruby — десктопное приложение для Windows, которое записывает звук лекции (с микрофона или прямо из вкладки браузера), а в браузере ещё и делает скриншоты слайдов, и с помощью Gemini API превращает всё это в структурированный markdown-конспект: заголовки, буллеты, таймкоды.

🔗 **Сайт:** [kyouki-ai.github.io/ruby](https://kyouki-ai.github.io/ruby/)

## Возможности

- **Живой конспект** — слова и слайды появляются на экране прямо во время лекции.
- **Без браузера** — запись с микрофона ноутбука прямо в приложении, для лекций в аудитории.
- **Запуск из приложения** — старт записи в браузере одной кнопкой, без попапа расширения.
- **Чат по всем конспектам** — можно спросить «какое дз по матеше», и Ruby сам найдёт нужный предмет среди всех лекций.
- **Всё на диске пользователя** — конспекты хранятся обычными папками (предмет → лекция → `notes.md`), без привязки к облаку.
- **Один бесплатный ключ** — работает на бесплатном тарифе Gemini, без карт и подписок.
- **Именные чаты** — отдельные сохраняющиеся диалоги (например «ДЗ», «Вопросы»), список слева.
- **Ловит домашку на слух** — уведомление и сохранённый момент со слайдом, как только препод озвучивает задание.
- **Русский и English** — переключаемый язык интерфейса, конспекты пишутся на языке лекции.

## Приватность

Звук лекции, слайды и распознанный текст отправляются в Gemini API (серверы Google) для расшифровки и сборки конспекта — это не анонимно, и мы не делаем вид, что иначе. Сам конспект и API-ключ хранятся локально на диске пользователя, ключ — в зашифрованном виде.
